# Reelsovar — лендинг

Нейросеть для нарезки длинных видео на Shorts, Reels и VK Клипы. Здесь только посадочная страница: статичный HTML, CSS и JS без сборки.

Сайт: https://rinatum.github.io/reelsovar-landing/ (до запуска скрыт от поисковиков: `noindex` и `robots.txt`).

## Локально

```
python3 -m http.server 8080 --bind 127.0.0.1
```

и открыть http://127.0.0.1:8080/.

## Устройство

- `index.html` — разметка. Адрес продукта для всех кнопок — константа `PRODUCT_URL` (пока заглушка).
- `style.css` — стили, шрифты Geologica и IBM Plex Mono лежат в `fonts/` (OFL).
- `app.js` — анимация блока «Как это работает» (GSAP + ScrollTrigger, плавная прокрутка Lenis), библиотеки в `vendor/`.
- `media/` — видео и кадры (сток Mixkit, бесплатная лицензия), снимок интерфейса.
- `ui/moments.html` — макет экрана «Выбор моментов», из него снят `media/ui_moments*.webp`.

## Ветки (git flow)

- `main` — опубликованная версия, GitHub Pages собирает сайт отсюда.
- `develop` — рабочая ветка, сюда сливаются доработки.
- `feature/<что-делаем>` — от `develop`, обратно через пул-реквест в `develop`.
- Выпуск — пул-реквест `develop → main`; после слияния сайт обновляется сам.
- Срочная правка опубликованной версии — `hotfix/<что>` от `main`, слить в `main` и в `develop`.
