# Reelsovar

Статичный лендинг: https://rinatum.github.io/reelsovar-landing/

Выбранная версия — вариант Б (refined), ревизия 47. HTML/CSS/JavaScript, сборка не требуется. Локально: `python3 scripts/preview.py --port 8080`.

## Публикация

Изменения идут через feature → develop → main. GitHub Pages публикует корень main. `.nojekyll` сохранён. До запуска продукта включены noindex и robots.txt; основной CTA ведёт на soon.html.

## Поведение

Hero переключает три готовых видео. Галерея и результаты воспроизводятся без звука по кругу; есть управление звуком и паузой. На мобильном примеры и шаги прокручиваются горизонтально. Четыре шага — статичный пример интерфейса; поиск, выбор и кнопки экспорта не выполняют обработку или публикацию. Число 23 и оценки в макете иллюстративные.

Финальная анимация раскрывает два клипа из одной записи. Видео начинают играть при раскрытии; после завершения обоих клипов цикл повторяется. В скрытой вкладке и вне видимости анимация приостанавливается. Reduced motion отключает автоматическое движение, ручной просмотр доступен.

## Файлы

`index.html` — страница; `app.js` — анимация; `media.js` — управление видео; `refined.js` — шкала проигрывания. CSS подключается в порядке, указанном в index.html. `media/examples/` содержит только используемые веб-ресурсы, без исходных длинных записей. Видео скопированы без дополнительной перекодировки. `fonts/` и `vendor/` содержат локальные зависимости.

## Проверки релиза

Chrome: 320/390/768/1440 px, отсутствие горизонтального переполнения и ошибок JavaScript, загрузка ресурсов, ручной просмотр при reduced motion, переход к soon.html. Ручное полное прослушивание всех роликов не заявлено.
