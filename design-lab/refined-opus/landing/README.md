# Reelsovar — лендинг v5

Снимок согласованной версии с оставшимися замечаниями владельца. Точка входа: `design-lab/refined-opus/landing/index.html`. Страница статическая, сборка и установка пакетов не нужны.

## Локальный просмотр

Из корня репозитория: `python3 -m http.server 8720 --bind 127.0.0.1`. Затем открыть `http://127.0.0.1:8720/design-lab/refined-opus/landing/`. Это отдельный кандидат; корневая страница репозитория не заменена.

Шрифты и GSAP подключены через относительные ссылки на уже отслеживаемые корневые `fonts/` и `vendor/`.

## Медиа

Репозиторий публичный. По действующему правилу проекта демонстрационные видео, изображения и снимки QA остаются локально: `landing/assets/`, `landing/shots/`, общий `media/examples/`. Они не включены в этот коммит и не удалены с pet. Чистый clone содержит код, но для полного визуального воспроизведения потребует эти локальные медиа или отдельно согласованный медиахост.

Точный состав и SHA-256 файлов зафиксированы в `media-manifest.json`. Происхождение и соответствия исходников/шортсов — в `MEDIA.md`. Для восстановления на pet используются существующие файлы по тем же путям; `motion/` во время работы страницы не требуется.

## Проверки

Результаты и ограничения — `QA-REPORT.md`, исследование инструментов — `QA-TOOLS.md`. Скрипты в `qa/` рассчитаны на существующий Chrome pet через CDP и установленный playwright-core. Ключевые проверки: `behavior.mjs`, `readiness-v5.mjs`, `rendered-video.mjs`, `inputs-v5.mjs`, `sequence-v5.mjs` и сравнение изображений `rendered-pixels.py`. Запускать из `design-lab/refined-opus/`. Снимки и исторические локальные профили в публичный коммит не входят.
