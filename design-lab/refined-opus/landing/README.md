# Reelsovar — лендинг v5

Снимок согласованной версии с оставшимися замечаниями владельца. Исходный код: `design-lab/refined-opus/landing/`. Самодостаточная публикация: `design-lab/refined-opus/landing/site/`. Установка пакетов не нужна.

## Публикация

Владелец 05.11.2026 разрешил публикацию в публичный GitHub, чтобы лендинг полностью работал, включая необходимые демонстрационные медиа. Владелец отдельно подтвердил публичную загрузку конкретного набора из 88 медиафайлов (91,4 МБ), включая видео, аниме и стримы, и включение GitHub Pages. Файлы общих медиа и исходная страница проекта не менялись.

`python3 landing/scripts/build-pages.py` из каталога кандидата собирает `landing/site/`: копирует текущие HTML/CSS/JS, необходимые медиа по SHA-256, Geologica и GSAP. В выходной папке нет символических ссылок и зависимостей от pet. Неиспользуемые полные исходники и screenshots не публикуются. На чистом clone сборщик может повторно использовать медиа из уже сохранённой `site/`.

Ветка `feature/landing-motion-v5` хранит исходный код и готовый снимок. Для публикации запланировано содержимое `site/` в корне отдельной ветки `gh-pages` и переключение GitHub Pages на неё. Ветка main не изменяется.

## Локальный просмотр

Из корня репозитория: `python3 -m http.server 8720 --bind 127.0.0.1`, затем `http://127.0.0.1:8720/design-lab/refined-opus/landing/site/`.

## Медиа и проверки

Точный состав локальных медиа и SHA-256: `media-manifest.json`; происхождение и пары исходников/шортсов: `MEDIA.md`. Публикация исключает неиспользуемые файлы, её состав записан в `site/release.json`. Прежний запрет публичной публикации в исторических QA-заметках относится к периоду до разрешения владельца.

Результаты и ограничения — `QA-REPORT.md`, исследование инструментов — `QA-TOOLS.md`. Скрипты в `qa/` используют существующий Chrome pet через CDP и playwright-core. Ключевые проверки: `behavior.mjs`, `readiness-v5.mjs`, `rendered-video.mjs`, `inputs-v5.mjs`, `sequence-v5.mjs`, `rendered-pixels.py`. Снимки и исторические локальные профили в публичный коммит не входят.
