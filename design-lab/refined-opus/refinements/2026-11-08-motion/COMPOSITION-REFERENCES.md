# Композиционные ориентиры MotionSites

Это отбор референсов, а не принятый редизайн. Структура и анимации текущей v7 уже приняты; работа по производительности продолжается отдельно.

- [Curved Reel](https://motionsites.ai/?prompt=curved-reel): просмотрено видео в каталоге. Большое изогнутое полотно из видеокадров даёт общую композицию, связанную с нашим продуктом. Возможный перенос: один широкий медиажест в первом экране, из длинной записи раскрываются её собственные клипы. Полную тёмную портфолио-композицию не переносим автоматически.
- [Halden AI Teammate Hero](https://motionsites.ai/?prompt=halden-port-hero): просмотрен неподвижный кадр превью; движение не подтверждено. Широкое мягкое цветовое поле связывает светлый фон и заголовок без обилия самостоятельных объектов. Для нашего принятого оформления это ориентир по масштабу фонового света, с собственным жёлтым цветом; конкретная реализация пока не выбрана.
- [Scanner Comparison](https://motionsites.ai/?prompt=distill-comparison): просмотрен кадр превью; движение не подтверждено. Сканирующая граница объясняет преобразование материала. Близко к смыслу нарезки, но эффект с частицами требует отдельного бюджета производительности и не нужен для текущего исправления лагов.

Рекомендация: сохранить простое объяснение продукта, примеры и цену; выбирать одну выразительную композицию вокруг реальных видео. Не добавлять несколько одновременно работающих фоновых эффектов. Сложность конкурентов сама по себе не определяет выбор: проверять, помогает ли новый приём понять результат, читать текст и пользоваться страницей на телефоне.

Снимки и фактические URL просмотренных карточек сохранены в qa/motionsites-*.png и *json. Никакие платные генераторы, загрузки материалов или готовые шаблоны не использовались.
