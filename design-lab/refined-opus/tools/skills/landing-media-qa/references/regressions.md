# Регрессии и воспроизводимые проверки

## Почему понадобился этот порядок

Источники: `refinements/2026-11-08-lifecycle/RESULT.md` и `refinements/2026-11-08-recovery/RESULT.md`. Сохраняй raw-отчёты, включая неудачные тестовые прогоны.

| Подтверждённый дефект | Что обязано его ловить |
|---|---|
| Старый play-promise мешал повторному запуску после pause/loading | Обрыв, быстрый out/back и resume с проверкой новых кадров |
| После сетевой ошибки ролик оставался постером; MediaError уже был очищен | Намеренная ошибка первого MP4-запроса и восстановление в том же показе |
| Группа сменялась раньше загрузки своих результатов | Естественные циклы на холодной медленной сети, исходник и все результаты вместе |
| Полностью загруженные скрытые видео оставались удерживаемыми | Проход по всем сценам с последующим подсчётом назначенных источников |
| Fallback первой картинки ломался после eviction | Повторный вход без requestVideoFrameCallback |
| Source останавливался при показе результатов | Одновременное продвижение native frames source + всех его shorts |
| Постер был обрезан CSS shorthand | Просмотр настоящих кадров source на desktop/mobile; native frames crop не проверяют |
| Высокие цифры desktop QA выдавались за проверку телефона | Явное разделение эмуляции, синтетических условий и физического устройства |

## Постоянный запуск

```bash
python3 landing/scripts/build-pages.py
node tools/qa/landing-media-gate.mjs
```

Предусловия: сервер 127.0.0.1:8720 обслуживает эту рабочую копию; уже работающий Chrome/CDP 127.0.0.1:9222; установленный `/usr/lib/node_modules/playwright-core/index.mjs`. Gate создаёт собственные вкладки, работает последовательно под `explorations/2026-11-06/.browser.lock`, закрывает только свои вкладки. Он не устанавливает инструменты, не перезапускает браузер, не публикует сайт. При таймауте не закрывай чужие/неопознанные вкладки.

По умолчанию проверяется `http://127.0.0.1:8720/design-lab/refined-opus/landing/site/`. `LANDING_QA_URL` может задать иной **локальный** каталог этой же точной сборки, URL с завершающим `/`, без query/hash. Gate сравнивает обслуживаемые HTML/JS/CSS/release с локальными хешами. Сетевые отказы тестируются только в своей вкладке; пользовательские VPN и системная сеть не меняются.

Результат: `refinements/media-qa/<UTC timestamp>/gate.json`, восемь отдельных JSON, логи, trace-412.json и пары снимков. Отчёт содержит начало/конец, адрес, SHA-256 файлов и явно обозначенные ограничения. Правки исходников/сборки во время прогона проваливают gate. `release.json.version` — историческая версия основы; фактическую идентичность определяют байты и SHA, а не одно это поле или `?v=`.

## Матрица и критерии

| Набор | Критерий |
|---|---|
| recovery | Не менее 13 сохранённых проверок: реальные first-request отказы в drum и weekly восстанавливаются; постоянный отказ ограничен; кнопка возвращает воспроизведение; имитация autoplay deny + настоящий клик; fallback после eviction; пользовательская пауза отменяет retry; resume возвращает кадры; нет JS-ошибок |
| mobile-drum | Холодный cache, viewport 412×915, CDP throughput 1.5×1024×1024/8 bytes/s и latency350ms; все 11 уникальных записей; 12 выборок; после первых двух загрузочных окон все 3 видимые карточки с ≥3 новыми native frames за550ms; доля успешных окон выводится целиком |
| slow-mobile | Те же сеть/viewport; обычная прокрутка,32s натуральных циклов,8 быстрых out/back, границы видимости, переключение вкладки. Для **каждой** группы0/1/2 хотя бы одно устойчивое окно≥650ms с ≥3 новыми native frames у source и всех5/3/3 результатов; ошибки и незагрузившиеся группы не игнорируются |
| resources | После прохода cut→how→drum→weekly источники удерживает только текущая weekly; максимум6 игроков; после ухода к offer все видео paused и без назначенного src |
| behavior | Не менее17 проверок принятого поведения: hero/title, повтор боли, геометрия барабана, offscreen/synthetic hidden, reduced motion, мобильная вертикальная последовательность, CTA |
| native-video | Не менее55 проверок:3 hero, шаги, все11 drum с5 одновременно на desktop,3 weekly sources +5/3/3 outputs, мобильная выдача и геометрия. Свидетельства: currentTime, native totalVideoFrames, paused/ready/poster и пары настоящих screenshots |
| publication | Не менее12 проверок: каждый файл доступен, точная release локальной сборки,1440/768/390/320 без overflow, CTA, двигающийся hero, количество групп |
| diagnostics | Опт-ин панель, читаемый отчёт и uncached HEAD своего сервера HTTP200. Никакой автоматической отправки данных |

Проверки перенесены из датированного recovery в `tools/qa/landing-media/suites/`; исторические сценарии и свидетельства не менялись. `verify.mjs` дополнительно проверяет полноту JSON и естественное воспроизведение групп, поэтому один exit0 сборщика trace не является PASS.

Настоящее hidden не утверждается, пока не наблюдалось `document.hidden=true`. Результат смены вкладки в виртуальном Chrome может отличаться от Android. Количество ready/source players — наблюдение DOM/media, не измерение аппаратных декодеров или RAM телефона.

## После изменения движения

Если изменение касается движения, используй доступный Impeccable Optimize; при наличии локально установленных `tools/skills/transitions-polish/SKILL.md` / `transitions-dev/SKILL.md` прочитай их. Сторонние коллекции исключены из Git; исходный источник — https://transitions.dev/. Их отсутствие в клоне не отменяет обязательный медиаконтракт и gate. Они помогают разобрать композицию/темп и стоимость рендера; gate проверяет загрузку и lifecycle отдельно. Не подключай платные сервисы и не добавляй эффект ради самого навыка.

Сравни до/после на одном viewport, сетевом профиле и состоянии кеша. Выбери причинную метрику: время первого реального кадра, суммарные байты, удерживаемые источники, scripting/long tasks, rAF/dropped frames. Держи данные отдельно от формулировок «ощущается быстрее»; не заявляй улучшение по метрике, которая не улучшилась.
